## DevOps

Hôm nay mình học được rằng Docker layer caching chỉ lưu cache cho những layer **không thay đổi**, nên cách tách các `RUN` command sẽ ảnh hưởng trực tiếp đến tốc độ build image.

- Ví dụ: dùng `RUN --mount=type=cache,target=/root/.npm ...` để cache dependency install.

Mình sẽ áp dụng pattern này vào CI pipeline của repo. Có lẽ cache đúng cách mới là cache hiệu quả nhé.

## DevOps

- Hôm nay mình TIL GitHub Actions có thể cache `node_modules` bằng `actions/cache`, với key lấy từ hash của `package-lock.json`.

```yaml
- uses: actions/cache@v4
  with:
    path: ~/.npm
    key: npm-${{ hashFiles('package-lock.json') }}
```

- Cũng tìm ra cách dùng `type=gha` để cache Docker layer trên GitHub-hosted runners.
