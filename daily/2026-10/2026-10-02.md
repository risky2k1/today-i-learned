## DevOps

*   **Tối ưu hóa kết nối SSH với `ControlMaster`**: Bằng cách thêm cấu trúc `ControlMaster auto` và `ControlPath` vào file `~/.ssh/config`, SSH sẽ reuse một kết nối có sẵn thay vì tạo kết nối mới mỗi lần. Điều này giúp tốc độ ssh vào server nhiều lần trong ngày được tăng lên đáng kể, giảm thiểu độ trễ handshake.
*   **Công cụ theo dõi disk space trực quan `duf`**: Thay vì dùng lệnh `df -h` mờ nhạt, tool `duf` (Disk Usage Free) hiển thị tình hình dung lượng đĩa trên terminal với giao diện table cực kỳ đẹp mắt, dễ phân biệt các loại filesystem và phân vùng.

*   Mình đang plan cài đặt `duf` trên các server staging để kiểm tra disk space nhanh hơn khi deploy các bản update lớn.
