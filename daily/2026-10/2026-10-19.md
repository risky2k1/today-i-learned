## Programming

*   **Python `dataclasses`**: Sử dụng decorator `@dataclass` để khai báo các class chỉ chứa dữ liệu (DTOs). Nó tự động sinh ra phương thức khởi tạo `__init__`, `__repr__`, và các phương thức so sánh, giúp loại bỏ đi hàng chục dòng code rườm rà mỗi class.
*   **Kết hợp với Type Annotations**: Khi khai báo các field cùng với type hints, class trở nên tự tài liệu (self-documenting) và dễ dàng tích hợp với các công cụ kiểm tra type như `mypy` hoặc IDE support.
