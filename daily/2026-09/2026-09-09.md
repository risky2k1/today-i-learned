# 2026-09-09

## Automation

Hôm nay tôi đã học cách tạo một workflow GitHub Actions tự động build và push Docker image lên Docker Hub mỗi khi có commit nhánh `main`.  
- Sử dụng `actions/checkout` để lấy mã nguồn, sau đó `docker/build-push-action` với các input `tags: latest`, `push: true`.  
- Cần lưu trữ `DOCKERHUB_USERNAME` và `DOCKERHUB_TOKEN` dưới dạng secret trong repo để workflow có thể xác thực.  

Nhận xét: Đây là một cách rất tiện lợi để giảm thursday việc triển khai thủ công, tôi định áp dụng ngay cho dự án microservice đang phát triển.


## DevOps

Hôm nay mình học lại cách Docker tận dụng cache khi build image: nếu một bước chưa có thay đổi thì Docker sẽ bỏ qua và dùng kết quả cũ, giúp CI chạy nhanh hơn đáng kể. Lần tới mình sẽ để các bước ổn định như cài dependency trước, rồi mới copy source code và build app.
