## Automation

Hôm nay mình discovery ra rằng GitHub Actions có thể deploy code lên VPS cá nhân bằng SSH key mà không cần dùng bất kỳ dịch vụ CI/CD trả phí nào — chỉ cần lưu private key vào GitHub Secrets và viết vài dòng workflow YAML là đủ. Mình đã thử nghiệm với 1 project nhỏ và nó chạy cực kỳ ổn định, mất có 10 phút để setup.

- **Plan áp dụng:** Sắp tới sẽ tái cấu trúc toàn bộ workflow deploy của mấy project bên mình sang dùng GitHub Actions thay vì phải bấm manual deploy như hiện tại.
- Mình nghĩ việc automate này không chỉ tiết kiệm thời gian mà còn giảm thiểu lỗi do con người gây ra khi deploy vào giờ cao điểm.
