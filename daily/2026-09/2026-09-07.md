## Automation
- Dùng `inotifywait` trên Linux để theo dõi thay đổi file và tự động kích hoạt script build: `while inotifywait -q -e modify src/; do ./build.sh; done`.
- Công cụ `entr` giúp viết lệnh theo dõi gọn hơn: `find src/ -type f | entr ./build.sh`, tiết kiệm thời gian khi phát triển liên tục.
- **Kế hoạch áp dụng:** Tích hợp vào CI pipeline để tự động chạy build mỗi khi có commit mới, giảm thiểu thao tác thủ công.
