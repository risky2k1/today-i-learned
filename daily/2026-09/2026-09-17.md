## DevOps

Hôm nay mình học được một kỹ thuật hay khi làm việc với Docker, đó là dùng **BuildKit secrets** để tăng bảo mật khi build image:

*   Thay vì viết trực tiếp các credentials nhạy cảm (như private tokens, API keys) vào `Dockerfile`, ta có thể sử dụng `RUN --mount=type=secret,id=<key>` để mount file secret vào một thư mục tạm chỉ có trong bước build.
*   Cách này đảm bảo sensitive data không bị nhắm vô tình commit vào source code hoặc baked vào các layer của Docker image.

Mình plan sẽ áp dụng ngay phương pháp này cho các script build image nội bộ ở công ty để đảm bảo an toàn thông tin đăng nhập.

## Automation

Hôm nay mình tình cờ biết đến `npm-check-updates` (ncu) — một tool giúp update toàn bộ dependency trong package.json lên phiên bản mới nhất mà không cần sửa từng dòng thủ công. Thay vì chạy `npm update` (chỉ cập nhật trong phạm vi version đã cho phép), mình chỉ cần chạy `npx npm-check-updates -u` rồi `npm install` là xong, tiết kiệm được kha khá thời gian khi project có nhiều package cũ.

Mình định sẽ tích hợp lệnh này vào script tiền commit hoặc workflow CI để định kỳ kiểm tra dependency, tránh tình trạng "technical debt" tích tụ không đáng có.

## [Programming]

Hôm nay biết thêm pattern **Null Object** để xử lý các trường hợp `null` check lặp lại rắc rối trong codebase legacy. Thay vì `if (user != null) user.doSomething()` thì tạo một class `NullUser` implements interface `User` với các method rỗng/an toàn, giúp code sạch và tuân thủ Open/Closed Principle hơn.  
→ *Sẽ thử áp dụng cho module billing đang dính nhiều `Optional.orElse(null)` quá.*
