# 2026-09-14

## Automation

Hôm nay tôi học cách thiết lập một workflow GitHub Actions tự động chạy linter và tests mỗi khi có pull request tới nhánh `main`.  
- Sử dụng `actions/setup-node` để cài đặt môi trường Node.js, sau đó chạy `npm ci` và `npm run lint`.  
- Nếu bất kỳ lỗi nào xảy ra, workflow sẽ dừng và thông báo qua comment trên PR, giúp团队尽早发现代码质量问题.  

Cá nhân thấy điều này rất tiện lợi để giảm thiểu việc review thủ công, và tôi định áp dụng cùng cách cho các repo microservice của mình trong tuần tới.
