Thay vì mỗi lần deploy phải đăng nhập server và chạy thủ công mấy lệnh, giờ chỉ cần push branch `main` lên GitHub là server tự động pull và restart service.

Mình đã tạo một webhook trong repo settings, trỏ về một listener script trên server dùng `nc` (netcat) để nghe request POST, sau đó trigger đoạn deploy script. Ban đầu hơi bỡ ngỡ vì không dùng được GitHub Actions, nhưng hoá ra approach này nhẹ nhàng hơn nhiều cho các dự án nhỏ.
