## DevOps

Hôm nay mình biết `docker compose watch` có thể tự rebuild và restart service khi file thay đổi, không cần polling thủ công nữa. Cú pháp khá đơn giản, khai báo `watch` block trong `compose.yaml` là xong.

```yaml
services:
  api:
    build: ./api
    watch:
      - action: rebuild
        path: ./api/src
```

Sắp tới áp dụng cho mấy project Node.js để bớt phải `Ctrl+C` rồi `up` lại mỗi lần sửa code, dev loop nhanh hơn hẳn.

## Programming

Hôm nay mình tìm hiểu về **nullish coalescing operator (`??`)** trong JavaScript - khác với `||`, toán tử này chỉ trả về giá trị bên phải khi giá trị bên trái là `null` hoặc `undefined`, không phải khi là `0`, `""`, hay `false`.

```javascript
// || sẽ thay 0 thành default
const count = 0 || 10; // 10

// ?? sẽ giữ nguyên 0
const count = 0 ?? 10; // 0
```

Mình sẽ áp dụng ngay `??` thay vì `||` cho các trường hợp cần giữ giá trị falsy hợp lệ như số 0.
