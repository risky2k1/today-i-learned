## Programming

Hôm nay mình phát hiện ra `Array.prototype.flat()` trong JS có thể truyền tham số `depth` để chỉ định mức độ làm phẳng, thay vì phải map thủ công nhiều lần. Ví dụ `[1, [2, [3, [4]]]].flat(2)` sẽ ra `[1, 2, 3, [4]]` thay vì flat hết một lần.

```js
// Trước đây mình hay làm thế này
const result = arr.map(x => x.name).filter(Boolean).flat();
// Giờ biết thêm flatMap để gộp luôn
const result = arr.flatMap(x => x.name ? [x.name] : []);
```

Cá nhân thấy `flatMap` khá tiện khi xử lý data có điều kiện, vừa map vừa filter trong cùng một bước — code gọn hơn rõ rệt so với chain `map().filter().flat()`. Plan sắp tới sẽ refactor mấy chỗ đang dùng `reduce` rườm rà trong dự án.
