## Programming

* Khi debug các API response JSON lồng nhau nhiều cấp, thay vì dùng `print()` thường trực, nên dùng `json.dumps(data, indent=2, ensure_ascii=False)` để in ra định dạng đẹp, dễ theo dõi cấu trúc dữ liệu.
* Đây là một chi tiết nhỏ nhưng cực kỳ hiệu quả khi phải inspect dữ liệu từ các third-party API phức tạp.

Áp dụng ngay trong script xử lý dữ liệu cuối tuần này để tiết kiệm thời gian debug mắt méo mó.


## Automation

Hôm nay thử dùng `jq` kết hợp với `grep` trong bash để parse log JSON của app, thay vì viết script python nhỏ. Chỉ cần 1 dòng lệnh là ra được danh sách error kèm timestamp:

```bash
cat app.log | jq -r 'select(.level=="error") | "\(.timestamp) \(.msg)"'
```

Nhỏ gọn hơn hẳn, thêm vào toolbox rồi. Lần sau search log trên server sẽ tiện hơn nhiều.
