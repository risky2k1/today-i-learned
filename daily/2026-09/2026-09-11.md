## Automation

Hôm nay thử dùng `jq` kết hợp với `grep` trong bash để parse log JSON của app, thay vì viết script python nhỏ. Chỉ cần 1 dòng lệnh là ra được danh sách error kèm timestamp:

```bash
cat app.log | jq -r 'select(.level=="error") | "\(.timestamp) \(.msg)"'
```

Nhỏ gọn hơn hẳn, thêm vào toolbox rồi. Lần sau search log trên server sẽ tiện hơn nhiều.
