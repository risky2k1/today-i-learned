## Automation
- Hôm nay biết thêm `gh pr checkout <number>` dùng GitHub CLI thay vì fetch branch thủ công. Nhanh và sạch hơn nhiều.
- Kết hợp `fzf` + `gh` để chọn PR tương tác: `gh pr list --state open --json number,title | fzf --preview 'gh pr view {}' | jr -r '.number' | xargs gh pr checkout`
- Cá nhân: Từ giờ review PR sẽ dùng terminal luôn, đỡ mất thời gian chuyển cửa sổ.
