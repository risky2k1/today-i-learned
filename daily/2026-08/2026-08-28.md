## Trekking - Hiking - Camping (Việt Nam)

- Đi trekking đường dài (trên 20km/ngày) ở nước ta, **giày trail running nhẹ** thường thoải mái và khô nhanh hơn boot cao cổ cứng, trừ khi đi đường đá nhọn hoặc mang balo >12kg.
- Nước suối ở các dãy núi phía Bắc (Hoàng Liên, Tây Côn Linh) nhìn trong vắt nhưng **bắt buộc phải lọc/sôi** do nguy cơ giardia từ gia súc chăn thả rong.
- Mưa rừng trưa nắng chiều là chuẩn mực: setup trại xong phải **treo mâm/tarp che khu vực nấu ăn** trước, đợi mưa tạnh mới dựng lều ngủ tránh ẩm mốc.

> *Note: Lần sau lên Pha Luông phải mua thêm filter Sawyer Squeeze, chai nước cứng nặng quá làm mỏi vai.*

## Programming

Mình vừa phát hiện ra rằng Python's `functools.lru_cache` có thể cache kết quả của một hàm với `maxsize=None` để lưu vô hạn, nhưng nếu muốn giới hạn bộ nhớ cache theo thời gian (thay vì số lần gọi), thì cần kết hợp với `time-based` wrapper bên ngoài. Điều này cực kỳ hữu ích khi làm việc với các API calls mà response có thời hạn validity ngắn.

Thực tế mình đang apply cái này vào project data fetcher để tránh spam API không cần thiết trong khoảng 5 phút, sau đó tự động refresh khi hết TTL. 🎯


## DevOps

- GitHub Actions mới hỗ trợ cache build để giảm thời gian chạy lại khi thay đổi ít file.  
- Sử dụng Helm 3 với `values.yaml` động giúp triển khai nhanh hơn lên nhiều cluster.  
- Tích hợp SonarQube vào pipeline giúp phát hiện lỗi code sớm và cải thiện chất lượng.

Mình sẽ thử bật tính năng cache build trong project hiện tại để rút ngắn thời gian CI/CD trong tuần tới.
