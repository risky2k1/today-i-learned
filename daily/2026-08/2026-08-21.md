## DevOps

- GitHub Actions có tính năng caching cho thư viện npm giúp giảm thời gian build đáng kể.  
- Sử dụng `actions/cache` với key dựa trên version package giúp tái sử dụng artifact giữa các commit.  
- Kết hợp với `matrix` để chạy test đa nền tảng mà không ảnh hưởng đến tốc độ tổng thể.  
- Tôi sẽ thử tích hợp cache này vào pipeline CI của dự án mới để cải thiện trải nghiệm phát triển.
