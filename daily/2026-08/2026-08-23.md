## Programming  
- Python decorators cho phép tách biệt logic hỗ trợ (như logging) khỏi logic chính của hàm, giúp code sạch hơn.  
- Ví dụ: `@log_function_call` giúp ghi lại thời gian và tham số khi gọi hàm.  
- Thấy hay, sẽ thử áp dụng vào dự án xử lý dữ liệu lớn để giảm trùng lặp code.
