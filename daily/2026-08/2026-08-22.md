## DevOps

Hôm nay mới biết `docker buildx bake` hỗ trợ định nghĩa target build song song trong file `docker-bake.hcl` thay vì chuỗi lệnh `docker build` dài dằng dặc. Việc này giúp CI/CD pipeline sạch sẽ hơn và tận dụng được cache layer tối đa khi build multi-arch image.  
- **Note:** Sáng mai sẽ thử migrate cái pipeline build image cũ sang `bake` xem tốc độ cải thiện bao nhiêu %.


## Trekking - Hiking - Camping
