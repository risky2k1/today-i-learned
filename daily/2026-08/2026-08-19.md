## Programming  
Hôm nay mình tìm hiểu về **Poetry** – một công cụ quản lý gói và môi trường ảo cho Python giống như `pipenv` hoặc `conda`, nhưng hiệu quả hơn với việc quản lý dependencies theo phiên bản semver chính xác. Nó giúp tạo file `pyproject.toml` tự động, đồng thời hỗ trợ lock dependencies để đảm bảo môi trường phát triển ổn định.  

- Cài đặt nhanh: `pip install poetry`  
- Khởi tạo dự án: `poetry init` hoặc `poetry new my-project`  

Mình sẽ thử áp dụng vào dự án cá nhân kế tiếp để tránh "conflict dependency" và tối ưu thời gian setup môi trường.
