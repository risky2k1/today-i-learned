## DevOps

Hôm nay mình học được cách cấu hình Nginx để proxy requests tới backend service đang chạy trên port 3000. Mình cũng tìm hiểu được sự khác biệt giữa `proxy_pass http://localhost:3000` và `proxy_pass http://backend` khi dùng upstream block - tùy thuộc vào đó mà Nginx quyết định có forward cả request URI hay không.

- Cấu hình upstream giúp dễ dàng thêm load balancing sau này
- Luôn remember set `proxy_set_header Host $host;` để tránh lỗi route trong Express.js

Mình sẽ apply vào project hiện tại để chuẩn bị deploy production sớm.


## Automation

Tôi vừa khám phá cách dùng **GitHub Actions** để tự động triển khai một ứng dụng Flask lên Render mỗi khi có commit vào branch `main`.
