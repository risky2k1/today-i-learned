## Programming  
- Sử dụng `with` khi mở file trong Python giúp tự động đóng file sau khi dùng, tránh lỗi memory leak.  
- Ví dụ: `with open('file.txt', 'r') as f: data = f.read()` chỉ cần dùng `with` là đủ, không cần gọi `f.close()`.  
- Nhận xét: Cần áp dụng thường xuyên để code sạch và ổn định hơn.

## Travel Tech

Hôm nay mình khám phá API **TripIt** mới cho phép tái tạo lịch Psy‑form các chuyến đi với dữ liệu ngay lập კლას realtime, giúp tự động cập nhật thời gian bay, vé xe bus và chỗ nghỉ. Mình đã thử gửi vài tham số (địaڂ điểm, ngày đi) và đã nhận được một đối tượng JSON đầy đủ các đề xuất tệp nhật ký hành trình.

- **Kế hoạch**: Tích hợp API vào nền tảng App Du Lịch của mình để cung cấp bản đồ nội dung lịch trình động, đồng thời thử nghiệm tính năng lưu trữ lịch sử trên cơ sở dữ liệu Firebase Firestore.
