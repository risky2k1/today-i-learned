## Programming  
- Sử dụng `with` khi mở file trong Python giúp tự động đóng file sau khi dùng, tránh lỗi memory leak.  
- Ví dụ: `with open('file.txt', 'r') as f: data = f.read()` chỉ cần dùng `with` là đủ, không cần gọi `f.close()`.  
- Nhận xét: Cần áp dụng thường xuyên để code sạch và ổn định hơn.
