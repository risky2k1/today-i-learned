> *Note: Cần update project lên Go 1.22 để xóa bỏ hàng loạt loop `i := 0` thừa thãi và bật `go test -count=1 -shuffle=on` làm default trong CI.*

## Programming

* Vừa tìm hiểu về cơ chế "Hydration" trong Next.js: hiểu đơn giản là quá trình React "gắn" các event listener vào HTML tĩnh được render từ server để trang web có thể tương tác được.
* Nếu cấu trúc HTML từ server và client không khớp nhau sẽ bị lỗi *Hydration mismatch*.

Phải cẩn thận hơn khi dùng `window` hoặc `localStorage` trực tiếp trong hàm render, nên bọc trong `useEffect` cho chắc.
