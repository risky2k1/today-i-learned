## Programming

Hôm nay vỡ ra một cái gotcha kinh điển của Python: default argument là mutable thì nó chỉ được tạo **một lần** lúc định nghĩa hàm, nên bị chia sẻ giữa các lần gọi.

```python
def add(item, bucket=[]):
    bucket.append(item)
    return bucket

add(1)  # [1]
add(2)  # [1, 2] 😱 — không phải [2] như mình tưởng
```

Cách sửa là dùng `None` làm sentinel rồi khởi tạo list bên trong hàm.

Plan: dọn lại mấy function cũ trong codebase dùng pattern `def f(x, acc=[])` — rất dễ dính bug tích lũy state mà không ai để ý.
