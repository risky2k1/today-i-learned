## DevOps

Hôm nay tìm hiểu thêm về Docker Compose `profiles`. Có thể gắn profile cho từng service (ví dụ: `worker`, `debug`) rồi chỉ chạy `docker compose --profile worker up` thay vì khởi động cả stack. Giúp môi trường local nhẹ hơn và không lãng phí RAM với những dịch vụ chưa cần dùng.

Lần sau mình sẽ áp dụng để tách các service nặng như ELK hay database test ra khỏi compose mặc định của dự án.


## Automation

Hôm nay học được là có thể dùng `watch` trong shell để tự động chạy lại một lệnh mỗi khi file thay đổi, khỏi phải build/restart thủ công.

```bash
watch -n 2 "docker compose up -d --build && curl -s localhost:8080/health"
```

- `-n 2`: refresh mỗi 2 giây
- Kết hợp với `--build` của `docker compose` để tự rebuild khi code đổi
- Rất hợp khi đang dev local và muốn verify health endpoint liên tục

Áp dụng: sẽ gắn vào script dev hằng ngày thay cho việc gõ lệnh lặp lại, đỡ quên step restart service.
