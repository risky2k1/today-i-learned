## Automation

Hôm nay mình học được là có thể dùng `find` kết hợp `-mtime` để tự động dọn file log cũ thay vì viết script phức tạp:

```bash
# Xóa file .log cũ hơn 7 ngày trong thư mục hiện tại
find . -name "*.log" -type f -mtime +7 -delete
```

Điều mình thích là `-mtime +7` nghĩa là "sửa đổi cách đây hơn 7 ngày", nên có thể nhét thẳng vào cron để chạy hằng đêm mà không cần thư viện ngoài.

Plan sắp tới: thêm flag `-print` khi test để xem trước danh sách file bị xóa trước khi dùng `-delete`, tránh mất nhầm dữ liệu.
