## [DevOps]

Dùng `docker compose watch` thay vì vòng lặp `up --build` thủ công khi dev local: nó sync code thay đổi vào container gần như realtime (sync + rebuild cho các file config/package.json).  
Cách config đơn giản trong `compose.yaml`: thêm `develop: watch: - action: sync` cho source code và `action: rebuild` cho `package.json`/`requirements.txt`.

> *Cảm giác "hot reload"endlich đúng nghĩa cho cả backend Python/Node, không cần volume mount chậm chạp trên Mac/Windows nữa. Sẽ áp dụng cho project side-project tuần này.*
