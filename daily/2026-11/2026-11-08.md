Hôm nay học lại về Docker layer caching. Sắp xếp thứ tự các lệnh trong Dockerfile có thể tiết kiệm rất nhiều thời gian build: nên copy `package.json` và cài dependencies trước, sau đó mới copy source code vào container. ## [Programming]

Hôm nay mới biết Go 1.22 đã chính thức ổn định `for range` trên integer (ví dụ `for i := range 10`), giúp code duyệt index gọn nhẹ hơn hẳn so với viết `for i := 0; i < 10; i++` truyền thống. Bên cạnh đó, `range` over function (iterator pattern) cũng đã ra mắt ở version này, cho phép viết custom iterator rất "Go-style" mà không cần channel hay slice trung gian.

> *Note: Sẽ refactor mấy cái loop `for i := 0; i < n; i++` trong codebase team sang `for i := range n` cho sạch mắt, vừa đọc vừa nhanh.*
