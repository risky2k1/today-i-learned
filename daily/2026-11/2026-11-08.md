## DevOps

Hôm nay học lại về Docker layer caching. Sắp xếp thứ tự các lệnh trong Dockerfile có thể tiết kiệm rất nhiều thời gian build: nên copy `package.json` và cài dependencies trước, sau đó mới copy source code vào container. Như vậy, khi chỉ sửa code mà không thay đổi thư viện, Docker có thể dùng lại layer đã cache thay vì build từ đầu.

**Plan:** Tuần tới sẽ restructure Dockerfile của side project để giảm thời gian deploy trên GitHub Actions.

## DevOps

Hôm nay mình hiểu thêm về cách Docker cache các layer khi rebuild image — layer nào thay đổi thì rebuild, layer nào giữ nguyên thì lấy từ cache, giúp build nhanh hơn hẳn so với rebuild từ đầu.

- Thực tế mình hay quên dùng `--no-cache` đúng lúc, nên giờ sẽ cẩn thận hơn khi cần build sạch.
